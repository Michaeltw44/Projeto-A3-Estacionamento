## Sobre o Projeto
    Este projeto consiste na modelagem de um banco de dados para o gerenciamento de um estacionamento, utilizamos o Modelo Entidade Relacionamento, depois passamos para o Diagrama Entidade Relacionamento e por ultimo o Modelo Fisico em SQL LITE. O sistema controla entrada e saida de veiculos rotativos (cobrados por hora) e de mensalistas, registrando pagamentos, ocorrencias, capacidade de vagas e vínculos com lojas conveniadas. 

## Como reproduzir o banco de dados 
    Para testar o projeto vamos utilizar o **DB Browser for SQLite** e execute os scripts da pasta sql/ na seguinte ordem:

1. 00-base-fornecida.sql: Cria as tabelas de marcas e modelos de veículos.
2. 01-schema.sql: Cria as tabelas que nosso grupo modelou com as chaves e restrições.
3. 02-dados.sql: Inserir os dados fictícios para teste e validação do projeto.
4. 03-consultas.sql: Contém as 17 consultas obrigatórias.
